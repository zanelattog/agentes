# Vibe Coding Toolkit adaptation

[Português](toolkit.md) · [Back](../README.en.md)

Based on [Matheus Gomes, revision 790a895](https://github.com/soumatheusgomes/vibe-coding-toolkit/tree/790a895304e0c08b70a5b215c9d334f1c86b816c). The MIT license is retained in [licenses](../licenses/VIBE-CODING-TOOLKIT-MIT.txt).

Verification, continuity and handoff practices were adapted from `templates/AGENTS.md.template` and `templates/task-handoff.md.template`. `docs/07-harness-evaluation.md` informed the distinction between installation, model responses and observed execution.

These practices are embedded in every TOML; no extra pasted prompt is needed to supply them to a profile. Version 2.0 has eleven profiles. It does not bundle the complete toolkit, plugins, MCP servers, a Next.js stack, hooks, model changes or paid APIs.

The installer does not write global AGENTS.md or replace project instructions. Actual tools and permissions remain necessary. A profile does not install a video editor, image generator, browser or CRM.

Toolkit updates are references to review, not code automatically executed on your machine. Pinned source revisions make adaptation traceable. Intelligence gains, token savings and conversion rates are not guaranteed.
